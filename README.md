# 🎓 Информатика: Интерактивті оқу және жаттығу платформасы 2.0

> **👨‍🏫 Жетекшісі:** Алишев Сейткасын  
> **💡 Жоба:** AI Tabys _Tegin bilim | Sake_AI  
> **📚 Мақсатты топ:** 7-11 сынып оқушылары мен информатика пәні мұғалімдері  

Бұл қосымша мектеп бағдарламасына және олимпиадалық дайындыққа арналған **10 негізгі тақырыпты** интерактивті түрде оқытуға, оқушылардың білімін нақты уақытта бағалауға және нәтижелерін деректер базасына сақтауға арналған.

---

## 🚀 Негізгі мүмкіндіктері

- 👤 **Оқушыны тіркеу жүйесі:** Аты-жөні мен сыныбын (7, 8, 9, 10, 11) таңдау арқылы жеке оқу траекториясын құру.
- 📖 **Толық теориялық курс:** Әрбір тақырып бойынша негізгі ұғымдар, ережелер мен формулалар.
- 📝 **Күрделендірілген есептер:**
  - 🟦 **В деңгейі (2 ұпай):** Орташа күрделіліктегі логикалық және есептеу тапсырмалары.
  - 🟥 **С деңгейі (3 ұпай):** Тереңдетілген және олимпиадалық күрделі есептер.
- 💡 **Ақылды көмекші (Guide) және Талдау (Solution):** Әр есепке бағыт беруші кеңес және тексеруден кейін толық шешу қадамдары.
- 📊 **SQLite деректер базасы:** Оқушылардың барлық жинаған ұпайлары, пайыздары мен уақыты сақталады (`students_results.db`).
- 👨‍🏫 **Мұғалімнің басқару панелі (Teacher Dashboard):**
  - Парольмен қорғалған кіру (`sake2026`).
  - Барлық оқушылар нәтижесінің нақты уақыттағы кестесі.
  - Сынып және тақырып бойынша динамикалық фильтр.
  - Нәтижелерді Excel қолдайтын CSV форматында жүктеп алу (`utf-8-sig`).
  - Базаны тазарту мүмкіндігі.

3. Ақпаратты кодтау, екілік код ASCII, UNICODE
4. Санау жүйелері
5. Желінің өткізу қабілеті
6. Ip-адресте және маска
7. Логикалық элементтер және ақиқат кестелері
8. Электронды кестелер - Абсолютті, салыстырмалы және аралас сілтемелер
9. Python бағдарламалау негіздері
10. Html және Sql деректер базасын құру
